還沒開始投資？先做好這 3 件事

存好緊急預備金、處理高利率負債、寫下目標，打好地基再學投資。

想開始投資之前，先把地基打穩。下面這 3 件事做好，之後遇到市場上下波動，心裡也比較踏實。

第 1 件：存好緊急預備金

建議存到 3–6 個月的生活費，放在隨時領得出來的地方。這樣意外發生時，你不用被迫賣掉手上的投資。

第 2 件：先處理高利率負債

信用卡循環利息動輒年利率 10% 以上。先把它還掉，等於拿到一筆確定的「報酬」。

第 3 件：寫下你的目標

先想清楚這筆錢什麼時候要用。1 年內就要用的錢，通常不適合放進波動大的資產。

小總結

  • ✓ 預備金
  • ✓ 高利率負債
  • ✓ 目標

三項都打勾了，再來學怎麼投資。
